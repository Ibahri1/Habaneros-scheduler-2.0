Calendar Subscription

This link is private. Anyone with this link can see your scheduled shifts.

iPhone

  1. Copy the calendar link.
  2. Open Settings.
  3. Calendar > Accounts > Add Account > Other.
  4. Add Subscribed Calendar.
  5. Paste the link and save.

Google Calendar

  1. Copy the calendar link.
  2. Open Google Calendar on desktop.
  3. Other calendars > From URL.
  4. Paste the link and add calendar.

Outlook

  1. Copy the calendar link.
  2. Open Outlook Calendar.
  3. Add calendar > Subscribe from web.
  4. Paste the link.
